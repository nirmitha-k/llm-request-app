Simple LLM Request App

A Streamlit web application that sends user prompts to a Large Language Model (LLM) and displays the response in real-time. 

## Tech Stack
- **Python**
- **Streamlit** (Frontend/UI)
- **Groq API** (LLM Backend)
- **OpenAI Python SDK** (Used to make the API requests to Groq)

https://llm-request-app.streamlit.app/
